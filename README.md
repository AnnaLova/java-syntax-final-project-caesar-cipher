Консольное Java-приложение для шифрования и расшифровки текстовых файлов с использованием шифра Цезаря.

## О проекте

Проект создан в рамках обучения на курсе JavaRush.

Программа позволяет шифровать и расшифровывать текстовые файлы с помощью шифра Цезаря.

Пользователь может:
- зашифровать текст, указав ключ шифрования;
- расшифровать текст, указав известный ключ;
- выполнить автоматическую расшифровку методом Brute Force, если ключ неизвестен.

Шифрование и расшифровка выполняются путём циклического сдвига символов алфавита на заданное количество позиций.

При использовании Brute Force программа перебирает возможные ключи, расшифровывает текст для каждого из них и оценивает полученные варианты по набору признаков, характерных для русского языка. В качестве результата выбирается вариант с наибольшей оценкой.

## Возможности

* Шифрование текстовых файлов.
* Расшифровка с использованием известного ключа.
* Автоматическая расшифровка методом Brute Force без указания ключа.
* Оценка вариантов расшифровки на основе характерных признаков русского текста.
* Работа с файлами в кодировке `UTF-8`.
* Проверка корректности ключа шифрования.
* Сохранение результата в отдельный файл.
* Сохранение символов, отсутствующих в алфавите, без изменений.
* Защита исходного файла от перезаписи.

## Используемые технологии

## Алфавит

Используется русский алфавит в нижнем регистре, дополненный буквой `ё`, 
а также некоторыми знаками препинания и пробелом.

**Перед шифрованием и расшифровкой текст переводится в нижний регистр.**
